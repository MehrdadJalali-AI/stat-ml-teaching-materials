Section 2

Logistic regression and the decision threshold

Despite the name, logistic regression is a classifier. It computes a linear score, squashes it into a probability between 0 and 1, then compares that probability with a threshold to get a class label.

1 · linear scorez = β₀ + β₁x₁ + … + βnxn
2 · sigmoid → probabilityp = σ(z) = 11 + e−z
Tumour size → malignant? Move the threshold
Lower threshold → higher recallMore cases are flagged positive, so fewer are missed. Preferred in medical screening, where missing a disease (FN) is the expensive error.
Higher threshold → higher precisionOnly confident cases are flagged positive, so there are fewer false alarms. Preferred in spam filtering, where losing a real email (FP) is the expensive error.
Section 3

Logistic and classification functions

Sigmoid

σ(z) = 1 / (1 + e−z)

Output 0…1 = a probability. Used for binary classification (spam vs. not spam).

Softmax

pi = ezi / Σj ezj

Turns K scores into K probabilities that sum to 1. Used for multi-class problems (cat / dog / bird).

tanh

tanh(z) ∈ (−1, 1)

Zero-centred. Mostly an activation in neural-network hidden layers, not a final classifier output.

Section 4

Decision trees, entropy and information gain

A decision tree classifies by asking a sequence of simple questions about the features, like a flowchart, until it reaches a leaf with a class label. Each split is chosen to make the groups purer.

Entropy (impurity)H(S) = − Σ pi log₂ pi
0 = pure · 1 = 50/50 (binary)
Information gainGain(S, A) = H(S) − Σv |Sv||S| H(Sv)
Entropy vs. Gini

Slide example: 6 negatives and 2 positives → p₊ = 0.25 → H = −0.75·log₂0.75 − 0.25·log₂0.25 ≈ 0.81. Scikit-learn's default criterion is Gini, 1 − Σpi². It behaves almost the same and is faster to compute.

ID3 step by step: who buys a computer?

ID3 picks the attribute with the highest information gain at every node, then repeats recursively on each branch until the groups are pure. Click an attribute to split the selected node.

Build the ID3 tree yourself

The Student_ID trapAn ID column gives every row its own pure branch, so its information gain is the maximum possible (0.940 here). Yet it predicts nothing for a new customer. Gain ratio (C4.5) divides the gain by the split's own entropy, which punishes attributes with many values. Tick “include Customer_ID” above to see it happen.

Single decision tree

Interpretable, handles non-linear patterns and interactions. Very deep trees overfit: they memorise instead of learning. Control this with max_depth or pruning.

Random forest

Many trees on bootstrapped data and random feature subsets, combined by majority vote. More stable and accurate.

Gradient boosting

Trees built sequentially, each one fixing the previous trees' errors. XGBoost, LightGBM and CatBoost are often the best choice for tabular data.

Section 5

K-Nearest Neighbours (KNN)

How it works

Instance-based: there is no real training phase; KNN just stores the data. To classify a new point, find its k closest training points and take a majority vote (for regression, take their mean).

Trade-offs

✓ simple, no assumptions, multi-class, works for regression too
✗ slow and memory-hungry on big data, sensitive to irrelevant features and imbalance, needs feature scaling

Section 7

Overfitting, underfitting and the bias–variance trade-off

Underfitting = high bias

Model too simple. Poor on both training and test data (e.g. train 60 %, test 58 %). Fix: more complexity, better features, less regularisation, train longer, boosting.

Overfitting = high variance

Model too complex: it memorises noise. Excellent on training data, poor on new data (e.g. train 99 %, test 68 %). Fix: simpler model, regularisation, pruning, more data, cross-validation, early stopping, dropout, augmentation.

Section 8

Concept drift: when the world changes

Concept drift happens when the relationship between the inputs and the target changes over time: spammers invent new tricks, fraud patterns evolve, user preferences shift. A model that was accurate last year quietly gets worse.

Loan-default model in production

This month's data · solid line = model, dashed = true boundary

Model accuracy by month

Retrain regularly

Update on fresh data (schedule or trigger).

Online learning

The model adapts continuously as data streams in.

Windowing & weighting

Train on recent data, drop or down-weight old data.

Ensembles

Combine models trained on old and new data.

ADWIN

Adaptive windowing: shrinks the window when the distribution changes significantly, which triggers an update.

DDM

Drift detection method: watches the error rate and its variance and flags drift when they cross thresholds.

Not every drop is driftA one-week dip during Black Friday that recovers by itself is a temporary spike. Retraining on it would be a false alarm. Applicants with lower incomes but the same income→risk relationship is data (covariate) drift: inputs change, the concept doesn't. Monitor both, but react differently.
Section 9

ROC curve and AUC

The ROC curve plots the true-positive rate (recall) against the false-positive rate for every possible threshold. AUC is the area under it: 1.0 = perfect separation, 0.5 = random guessing. It compares models independently of any one threshold.

Section 10

Model selection and hyperparameter tuning

1 · Trial and error

Try a few candidate models on the same split or CV folds.

2 · Algorithm traits

Interpretable? Non-linear? Needs scaling? Small or big data?

3 · Domain knowledge

In medicine, avoiding FN can matter more than accuracy.

4 · The right metric

Accuracy (balanced), precision (FP costly), recall (FN costly), F1 (imbalanced), ROC–AUC (threshold-free).

5 · Generalisation

Good on unseen data and stable across CV folds.

Hyperparameters

Set before training: KNN k, tree max_depth / min_samples_split, logistic C. Search them with grid or random search + CV.

Grid search for KNN's k with 5-fold CV

Training accuracy is always 100 % at k = 1 because every point is its own nearest neighbour, which is useless for choosing k. Choose k with the CV score, then report the untouched test set once at the very end.

from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import classification_report, roc_auc_score

pipe = make_pipeline(StandardScaler(), KNeighborsClassifier())
grid = GridSearchCV(pipe, {"kneighborsclassifier__n_neighbors": range(1, 32, 2)}, cv=5, scoring="f1")
grid.fit(X_train, y_train)
print(grid.best_params_, grid.best_score_)
best = grid.best_estimator_
print(classification_report(y_test, best.predict(X_test)))      # test set used ONCE
print("AUC", roc_auc_score(y_test, best.predict_proba(X_test)[:, 1]))
